## Confirmed findings and reproductions

All seven findings below are P2 correctness/security issues. Original line numbers refer to `af9be8133a67`; links point to the corrected production paths.

1. **An unrelated migration conflict prevents listener cleanup.** Original `network/firewall-policy-v2.ps1:153` calls `Legacy` even for a typed Disable. Start RTSP, introduce an unrecognized same-display-name SRT legacy allow (for example, Profile Private), then stop RTSP. `finish_restream_stop` calls `retire_firewall` and the policy throws before disabling the exact owned RTSP rule. Disable now checks and retires only its requested owned role; ensure/install still reject migration conflicts. The pure provider regression reproduced the enabled leftover rule and now verifies cleanup while preserving the conflicting rule, a Block and a foreign-program rule. See [policy](../../src-tauri/src/network/firewall-policy-v2.ps1#L152).

2. **Maintenance can erase uncertainty about an earlier native operation.** Original `network/firewall-policy-v2.ps1:218` sets `uncertain=false` after disabling only the last prepared template. Install with a recognized legacy candidate and have its removal throw after both templates were prepared. The catch verifies the last template but has not established the legacy removal's outcome. Maintenance now retains uncertainty for those other effects; only a single-role Ensure can resolve its uncertainty through that cleanup. Cleanup also rejects ambiguous or changed ownership. The fake removal-failure regression failed before the fix and now passes, including an idempotent retry with every allow remaining disabled. See [cleanup](../../src-tauri/src/network/firewall-policy-v2.ps1#L215).

3. **Stop loses an older retained firewall lease after listener replacement.** Original `streaming/mod.rs:1489` cleans only the stored listener's generation. Let retirement of SRT generation N be unavailable because the shared native executor is busy, then start RTSP N+1 with unavailable automation, which is permitted. After native access becomes available, Stop tears down N+1 but never retries the retained SRT lease N. Stop now captures the policy lease separately and retires it through the existing generation check. A loopback listener regression reproduced the retained lease after Stop and passes with the fix. The existing newer-generation preservation regression still passes. See [Stop](../../src-tauri/src/streaming/mod.rs#L1505).

4. **A delayed topology observation overwrites a recovered listener in the same generation.** Original `streaming/mod.rs:1372` checks the explicit Start generation, which automatic recovery deliberately retains. Pause an observation at the lifecycle lock; let recovery publish a new listener instance and its successful binding snapshot; then complete the earlier failed observation. It overwrites the current snapshot with Unknown and can also request an unnecessary explicit rebind. Publication now checks the existing listener instance counter as well as generation/revision. The deterministic in-memory race test failed before the fix and now preserves the recovered snapshot. See [publication fence](../../src-tauri/src/streaming/mod.rs#L1381).

5. **Unknown wildcard binding status does not recover without a topology change.** Original `network/bindings.rs:238` returns before notifying StreamManager when its inventory fingerprint is unchanged. Let the watcher successfully observe inventory A, let Start's separate native read transiently fail, then let subsequent watcher reads again return A. The listener stays Unknown indefinitely despite successful observations. Refresh now delivers those observations to the listener while emitting frontend change events only for changed inventory. Known scopes at the same revision skip additional resolution; Unknown scopes can recover. Coverage verifies that a successful observation at the same revision repairs Unknown without changing listener health. See [refresh](../../src-tauri/src/network/bindings.rs#L229) and [listener consumer](../../src-tauri/src/streaming/mod.rs#L1315).

6. **Ignored extraction/deletion failures can be reported as successful installation or uninstall.** Original `installer/installer.nsi:440,589` checks the main executable extraction but not the resource batch or payload deletion. On an isolated fixture, hold a bundled DLL open without write/delete sharing and choose Ignore when extraction fails; alternatively uninstall with that DLL locked. Maintenance can succeed independently of media loading, and the installer previously continued through success/registration removal. NSIS documents the resulting error flags for [File](https://nsis.sourceforge.io/Reference/File) and [Delete](https://nsis.sourceforge.io/Reference/Delete). Required resource, executable, uninstaller and registration operations now enter the existing nonzero incomplete-transaction path on error. Uninstall keeps the maintenance image until resource deletion succeeds. Checks precede the GetSize macro, which resets the error flag. Seeded source-contract regressions and compilation cover these branches; actual file-lock/Ignore behavior remains isolated Windows qualification. See [extraction](../../src-tauri/installer/installer.nsi#L440) and [deletion](../../src-tauri/installer/installer.nsi#L609).

7. **Default uninstall prevents the next installation.** Original `installer/installer.nsi:671` clears the installation location only when Delete app data is selected, while `installer/transaction.nsh:125` rejects a saved location without an UninstallString. Uninstall with the default unchecked checkbox, then run the installer: it reports an unsupported predecessor even though standalone uninstall just completed. Installation identity is now removed independently of profile deletion. Preflight also accepts the residue left by older uninstallers only when the uninstall registration and both executable/uninstaller images are absent. Existing images or registered predecessors still take the strict predecessor/relocation checks. Source contracts cover unconditional identity cleanup; the generated script compiles. See [identity removal](../../src-tauri/installer/installer.nsi#L696) and [legacy residue preflight](../../src-tauri/installer/transaction.nsh#L125).
