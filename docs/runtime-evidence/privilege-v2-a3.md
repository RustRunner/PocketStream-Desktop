## Implemented behavior

Firewall policy now uses the existing trusted, contained fixed-script runner and retained local executor. The single Rust role table supplies both runtime and maintenance policy: exact RTSP/SRT native names, one managed group, and disabled program-scoped install templates on TCP 8554/UDP 8890. Runtime preflight precedes enablement; full intended filter readback precedes Applied. Profile Any and unrestricted remote addresses remain deliberate defaults. Explicit binds resolve native GUID/MAC/index to the current alias and cannot silently widen to Any. Stop/failure/protocol replacement retires only its listener's policy lease; unavailable cleanup retains its lease and reports the failure. Generation and topology fences discard stale listener publication. Startup reports reconciliation failure even while the listener is stopped.

Query User and other Block rules are preserved. Relevant application blocks are reported separately from the verified owned Allow. Install migrates both protocols and every recognized legacy port/duplicate: disable and verify first, prepare disabled templates, then remove recognized legacy candidates. Exact historical broad shapes and matching already program-scoped shapes are the migration convention; an indistinguishable manual clone is also disabled. Foreign-program rules are preserved, and unrecognized broad shapes/native-name collisions produce incomplete migration rather than a hardening claim. Structured diagnostics are bounded before native mutation; incomplete native results remain Uncertain.

The executable has a strict early `--firewall-maintenance install|uninstall` entry. It checks elevation and protected image/root ACLs, acquires HostOwner without reacquiring its parent's InstallGate, initializes no Tauri/media/profile log writer, and retains bounded native diagnostics in administrator-owned journals. Unknown/malformed arguments fail instead of opening the GUI. There is no nested elevation fallback.

The [custom NSIS template provenance](../../src-tauri/installer/provenance.json) pins CLI 2.10.1/bundler 2.8.1 and preserves the upstream source hash/license. The template acquires InstallGate in initialization, bounds host ownership/process/file-in-use checks, rejects relocation/unsupported predecessors, replaces supported installations in place, and propagates fixed maintenance failures. It removes the prior-uninstaller page and stock process-kill calls. MUI cancellation hooks and terminal callbacks release the transaction. Interactive launch is queued until finish-page shortcut callbacks complete; silent/updater relaunch also follows release. Post-replacement failure reports incomplete installation and preserves diagnostics. Native handle lifetime and all entry/exit modes still require isolated qualification.

Binding selection and exposure have separate consumers of the existing IP Helper reader and watcher registrations. `list_bind_interfaces` replaces `list_vpn_interfaces` one-for-one, completing the 46-command contract. Eligible up physical Ethernet/Wi-Fi and VPN interfaces carry stable IDs and candidate addresses. Legacy alias settings migrate once after unique native resolution; unresolved selections remain unavailable until chosen again. Persistence precedes publication and a reused alias cannot redirect a saved GUID.

Wildcard status enumerates every native IPv4 address, including secondary/adopted, APIPA, hidden virtual and loopback addresses, before display filtering. Existing interface/address notifications and their fallback/retry path publish topology independently of selected-camera refresh success. Explicit changes reuse listener recovery and re-ensure the firewall interface filter. Failed observations show Unknown. RTSP and SRT wildcard listeners use IPv4; URL/QR selection still excludes adopted/APIPA addresses and is separate from exposure. The card says **Bind / All addresses**, **Bound on …**, and separately reports Windows rule state/preserved blocks. These local facts do not establish remote reachability.
